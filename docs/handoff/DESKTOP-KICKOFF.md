# PC chat start-up (the one prompt for every Claude Code chat in LanternLive)

Open a new Claude Code session in the desktop app with the folder `C:\Users\Josh\Documents\LanternLive` and paste:

```
Start up as my Lantern Ring PC chat: pull C:\Users\Josh\Documents\LanternLive\site-10, then follow
site-10\docs\handoff\PC-CHAT-BRIEF.md section 1 in full and show me the menu.
Today: 
```

"Today" is optional: what you want this chat on (e.g. "proper lantern models from J:dark_lantern", "renders and
ratings only"). Two chats at once is fine: the second one sees the first in `pc-chats.txt`, takes another range and
leaves the watcher to the first.

To finish a chat: click **Close out** in its menu. It saves everything and gives you this prompt again with a
suggested "Today".
