## Gotchas (folded into the modeller skill)
- Blended transparency writes no depth: whole models went see-through at some angles. Use dithered (608).
- A builder that reloads its voxel module re-runs its monkeypatches: guard them so the original is kept once (609
  recursion).
- `C:\Users\...` inside Python strings is a unicode escape error, in heredocs too: use raw strings. A `\r` written into
  a path in a heredoc broke a script header (611).
- In the Terminal panel, `.\lr` is blocked by the execution policy: use `.\lr.cmd`.
- `pull_reviews.py` overwrites `ratings.json`, so ratings only in the file are lost (four 610 ratings were). Save chat
  ratings with `tools/pc/take_grid.py rate NNN CODE=RATING[:note]`.
- `pack_blend.py` wants its own argv: call it through a wrapper (`scratchpad\pack.py`).
- `SendUserFile` caps near 30 MB; a 12-take voxel `.blend` packs to 16-30 MB.
