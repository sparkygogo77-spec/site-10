# Tool style reference: "willo's better tools" (J's pick, 2026-10-13)

J's foundation for the hard-light **construct tools**. Source: a Java resource pack J sent
("AbdulKatools", pack_format 8). It holds only 2D item textures (no 3D models): 29 tools,
wood / stone / iron / gold / diamond / netherite x axe, hoe, pickaxe, shovel, sword, at 32x32 and 64x64.
`contact_sheet.png` shows them all at 6x. Treat these as a style guide, not assets to ship.

## The style
- **Long, slim handles.** The handle is about 2/3 of the diagonal, 2 px wide, dark with a
  diagonal wrap pattern, ending in a small faceted **pommel gem** in the material colour.
- **Thin, sweeping heads.** Axes are a big crescent blade with a back spike; hoes are a
  scythe-like curved hook; pickaxes are one wide, thin arc that tapers to needle points.
  Heads are narrow silhouettes, not chunky blocks.
- **Slim swords.** Long straight blade with a centre highlight line, thin crossguard,
  short wrapped grip and a gem pommel.
- **Shovels read as maces.** A round/oval head (gold, iron and netherite get a spiked
  mace head; wood and stone a flat round spade).
- **Shading.** Soft gradients along the edge (bright rim, darker spine), a clean outline,
  little noise. Head-to-handle ratio is small: elegance comes from long lines and curves.
