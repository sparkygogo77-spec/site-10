Chart library (owner only)

Record a coin's pool once a second from the free price feeds (DexScreener and Jupiter), then pick windows of exactly 1, 2.5 or 5 minutes. Saved windows are used by practice matches of that length when players choose "Recorded". Test networks and play money only.

The free game server forgets everything when it restarts. To keep windows, export them and commit the file to the repository in data/charts/; the server loads that folder every time it starts. Import puts an exported file back.
